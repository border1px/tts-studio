API 文档

想把文字变成 MP3？直接复制“文字转语音”中的命令。想把录音转成文字？看“语音转文字”，并填入自己的硅基流动 Token。示例已写好本站域名；上传文件时只需换成你电脑上的文件路径。

手机端可左右滑动查看完整命令和参数表。

调用前须知

本站目前的文字转语音接口可以直接调用，不需要账号或密钥。语音转文字需要你自己的硅基流动 Token；它只用于识别音频，不用于文字转语音。

给程序读取：如何判断是否需要密钥？

调用公开的配置接口：

curl 'https://tts.timecapsx.top/api/config'
  • authRequired 为 true：两个 POST 接口都要在请求头加入 X-API-Key，密钥由站长提供；为 false：不需要。
  • sttServerTokenAvailable 为 false：调用 STT 时必须在表单中提交自己的 token；为 true：可以省略。

当前本站这两个值均为 false。以后若配置变化，以接口的实时返回为准。该接口还会返回声音、风格和大小限制，但不会泄露密钥。

文字转语音

POST /v1/audio/speech 接收 JSON 或 UTF-8 TXT 文件，成功时直接返回 audio/mpeg。文本最多 10,000 字符。

curl -X POST 'https://tts.timecapsx.top/v1/audio/speech' \
  -H 'Content-Type: application/json' \
  -d '{"input":"你好，世界","voice":"zh-CN-XiaoxiaoNeural"}' \
  --output speech.mp3
JSON 字段默认值说明
input必填要合成的文本，最多 10,000 字符
voicezh-CN-XiaoxiaoNeural声音名称；可从 /api/config 获取推荐列表
speed1语速，0.5–2
pitch0音调，-50–50 Hz
volume0音量，-1–1
stylegeneral风格；可选值见 /api/config，并非每个声音都支持所有风格

上传 TXT 时改用 multipart/form-data：文件字段名为 file，可同时提交上表中的可选参数（不提交 input）。文件最大 500 KB，文本仍限 10,000 字符。

curl -X POST 'https://tts.timecapsx.top/v1/audio/speech' \
  -F 'file=@article.txt' \
  -F 'voice=zh-CN-XiaoxiaoNeural' \
  --output speech.mp3

语音转文字

POST /v1/audio/transcriptions 接收 multipart/form-data。file 必填，最大 10 MB，支持 mp3、wav、m4a、flac、aac、ogg、webm、amr、3gp。token 为调用者提供的硅基流动 Token；若部署者已配置服务端 Token，可省略。调用者 Token 优先。

curl -X POST 'https://tts.timecapsx.top/v1/audio/transcriptions' \
  -F 'file=@audio.mp3' \
  -F 'token=填写你的硅基流动Token'

成功响应为 JSON：{"text":"转录出的文字"}。如果没有服务端 Token 且请求未提供 token，接口返回错误。

错误响应

错误时返回相应的 HTTP 状态码和 JSON；客户端应检查状态码，而不是把错误体当作音频。

{"error":{"message":"请输入文字","type":"invalid_request_error","param":"input","code":"missing_input"}}

使用提醒

Edge TTS 使用非公开兼容协议，上游变更可能导致暂时不可用。服务不会保存请求文本、音频文件或生成结果。
